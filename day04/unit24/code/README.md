# LAB-24 · 콘솔을 내 손으로 (PL011)
- `make run`   : READY 배너 후 타이핑마다 [c] 에코 (종료 Ctrl+A, X)
- `make check` : 'OK' 파이프 주입 → [O][K] 자동 판정 → echo $? = 0
- `make check2`: 대문자 개조(수신 문자를 대문자로 에코) 완료 후 통과하는 목표 판정
- 실험: LCRH를 7비트(2u<<5)로 바꿔 QEMU의 무검사(관대함)를 확인·기록 후 원복
주의: QEMU pl011은 보레이트·프레임을 검사하지 않는다 — IBRD/FBRD는 실기 규약으로 유지한다.
