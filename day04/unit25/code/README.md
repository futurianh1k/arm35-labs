# LAB-25 · 알람 시계 길들이기 (SP804)
- `make run`  : 0.2초 리듬의 5틱과 DONE 배너 (종료 Ctrl+A, X)
- `make check`: DONE(5 ticks) 자동 판정 → echo $? = 0
- 실험 1: LOAD=1000000(1초)로 리듬 변경 후 원복 — "Load=시간"의 몸검증
- 실험 2: 선청소(INTCLR=1) 줄 주석 → 첫 틱 즉발 여부 관측(재현 안 됨도 유효 관측) 후 원복
- 심화: 틱을 1ms(LOAD=1000)로 올려 10ms 주기·듀티 30% 문자 파형(###.......) 20주기 출력
기준 클럭: versatilepb SP804 = 1MHz (틱=µs). QEMU는 틱 수·순서를 보장하며 벽시계 정합은 판정 밖이다.
