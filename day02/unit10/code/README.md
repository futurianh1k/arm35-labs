# H10 실습 코드 — 3종 명령어 세트 비교
| 파일 | 용도 |
|------|------|
| add5.c | add5(서식 뼈대)·sel(조건 처리) 비교용 |
| Makefile | make(3종 .dis+sizes.txt) / make dis(나란히 출력) |

읽기 프레임 3가지만: 리턴 방법 / 조건 처리(sel) / 명령 폭(기계어 자릿수).
완료 기준: 3종 본문 비교표 + 차이 3가지 주석 + .text 3값·T32/A32 비율 커밋.
측정 통제: .text 섹션만 계측하며, a64는 언와인드 표 억제 플래그 2종으로 .eh_frame을 제거해 순수 코드만 비교한다.
주의: sizes.txt 값은 환경(gcc 버전) 의존 — 헤더의 환경 줄과 함께 기록한다.
