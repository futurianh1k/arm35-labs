# 이론 평가 정답·채점 기준 (강사용 — 배포 금지)
1. 연산은 레지스터끼리, 메모리는 load/store로만 접근한다.
2. N=음수, Z=제로, C=캐리/차용없음, V=부호 오버플로.
3. CPSR의 T비트(BX/BLX로 전환).
4. 짧은 분기 제거로 파이프라인 이득 / 조건 불성립도 슬롯 소모·가독 저하(2점: 양면 서술).
5. 3단 파이프라인의 페치 선행 — 실행 시점 PC는 두 명령 앞(+8).
6. ISA 표현력(조건부·배럴시프터)과 컴파일러 최적화 전략이 명령 선택을 좌우(3점: 두 축 모두).
7. r0~r3.
8. 피호출자(callee) — 사용 시 저장·복원 의무.
9. 아래로(풀 디센딩), 공개 인터페이스에서 8바이트 정렬.
10. 다른 함수를 부르지 않고 r0~r3·스크래치로 충분할 때(LR 보존 불필요 조건 포함 시 만점).
11. 보장: 접근 제거·병합·상호 재정렬 금지 / 비보장: 원자성·타 관측자 순서(배리어 관할).
12. 컴파일러 최적화 방해·아키 종속·유지보수 저하 — 계약(클로버) 명시 실패 시 미정의(3점).
13. stride가 라인 크기를 넘는 순간 미스율 급증 — ns/elem 계단.
14. clean=캐시→메모리(쓰기 반영), invalidate=캐시 폐기(메모리를 새로 읽게).
15. TTBR0=유저(하위), TTBR1=커널(상위) — 문맥 전환은 TTBR0만 교체.
16. 장치로 보내기 전 clean, 장치가 쓴 뒤 invalidate 후 읽기(순서 뒤집힘=오염, 2점).
17. Break.Set↔break, Go↔continue, Data.List↔disas, Register↔info reg 중 3쌍.
18. 유저 포인터는 TTBR0 지도의 주소 — 검증 없이 커널이 밟으면 임의 매핑 접근 위험 → 검증 통로 필수(3점).
19. 1을 쓴 비트만 클리어 — RMW 금지, 해당 비트만 한 발.
20. CR 끄기 → IBRD/FBRD → LCR_H(굳힘) → CR 켜기.
21. 500,000.
22. 짧게 · 원인 제거(W1C/소비) · volatile 안전 통신.
23. 파이프라인 PC 선행으로 LR=복귀점+4 → -4 보정 / s=SPSR→CPSR 동시 복원(2점: 양쪽).
24. 점유(폴링 100%) · 지연의 우연성 · 다중 소스 확장성 — 세 항목 논증(3점).
25. fetch→unpack/patch→configure→compile→install→package.
26. 입력(소스·레시피·의존 산출물) 서명이 도장 이후 변경될 때.
27. config.txt=GPU 로더, cmdline.txt=커널.
28. depends=전제(문이 잠김, 사용자가 열어야) / select=견인(문이 따라 열림, 시스템이 실행).
29. 자원 획득(실기 ioremap 자리)과 인터페이스 개통(chrdev·fops 제출).
30. 원본 불변·변경분 분리 — 갱신 충돌 제거·변경 의도의 문서화·추적 가능성(3점: 사상+효과).
