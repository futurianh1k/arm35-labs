# ARM Processor 35H — 이론 평가 (50점, 30문항 × 배점표)
규정: 오픈북 카드 6장 허용 · 실기와 병행 가능 · 답안은 별지에 문항 번호와 함께 작성.
배점: 각 Day 6문항 — 단답 1점(문항 1~3), 서술 2점(문항 4~5), 논증 3점(문항 6) = Day당 10점.

## Day1 (아키텍처·ISA 기초)
1. RISC 로드-스토어 원칙을 한 문장으로 쓰라.
2. CPSR의 N·Z·C·V 각 깃발의 의미를 쓰라.
3. ARM 상태와 Thumb 상태 전환에 관여하는 레지스터 비트는?
4. 조건부 실행이 분기 대비 갖는 이점과 한계를 서술하라.
5. 파이프라인에서 PC가 +8을 가리키는 이유를 서술하라.
6. "같은 C 코드, 다른 명령 수"가 발생하는 원인을 ISA·컴파일러 관점에서 논증하라.

## Day2 (어셈블리·AAPCS·메모리)
7. AAPCS에서 인자 전달 레지스터 4개를 쓰라.
8. 콜리 세이브드 레지스터의 보존 의무는 누구에게 있는가?
9. 스택이 자라는 방향과 SP 정렬 규약을 쓰라.
10. 리프 함수가 스택 프레임을 생략할 수 있는 조건을 서술하라.
11. volatile이 보장하는 것과 보장하지 않는 것을 서술하라.
12. 인라인 어셈블리 남용의 위험을 이식성·최적화 관점에서 논증하라.

## Day3 (캐시·MMU·DMA·툴)
13. 캐시 라인 크기가 성능 측정 stride 실험에서 드러나는 방식은?
14. clean과 invalidate의 방향 차이를 쓰라.
15. TTBR0/TTBR1 두 지도의 분담을 쓰라.
16. DMA 전후 캐시 조작 순서를 계약으로 서술하라.
17. TRACE32와 gdb의 개념 등가(5호 카드) 세 쌍을 서술하라.
18. "커널이 유저 포인터를 못 믿는" 구조적 이유를 두 지도로 논증하라.

## Day4 (주변장치·인터럽트·계측)
19. W1C 레지스터의 클리어 규칙을 쓰라.
20. PL011 초기화 4막의 순서를 쓰라.
21. SP804에서 0.5초(1MHz)의 Load 값을 계산하라.
22. 핸들러 계약 3조를 서술하라.
23. subs pc, lr, #4에서 -4와 s의 이유를 서술하라.
24. 폴링 대비 인터럽트의 비용 구조를 세 항목으로 논증하라.

## Day5 (빌드·이미지·커널·드라이버)
25. 태스크 체인 여섯 정거장을 순서대로 쓰라.
26. 스탬프 스킵이 무효가 되는 조건을 쓰라.
27. config.txt와 cmdline.txt의 독자를 각각 쓰라.
28. depends on과 select의 방향 차이를 서술하라.
29. probe의 두 임무(오늘 기준)를 서술하라.
30. "원본 불변 4부작"(오버레이·레이어·bbappend·fragment)의 공통 사상을 논증하라.
