# LAB-15 · 지역성의 가격 실측
- `make run`   : N=2048 행/열 순회 시간·ratio, 합 검증 → exit 15
- `make sweep` : N=1024/2048/4096 비교(계층 어느 층까지 닿는가)
- `make stride`: 보폭 4/16/64/256B — 시간이 평평해지는 지점 ≈ 라인 크기
주의: -O1 + volatile 누산으로 루프 소거를 통제한다. 1회차는 워밍업이며 2회차 값을 채택한다.
QEMU 사용자모드에서도 게스트 메모리 접근은 호스트 메모리 접근이므로 호스트 캐시 효과가 그대로 나타난다(강의장 값은 재측정).
해석 팁: 순차 프리페처가 라인 미스를 숨기므로, "급등이 시작되기 직전의 마지막 보폭"을 라인 크기로 읽는다(위 예시라면 64B).
