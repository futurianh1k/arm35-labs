# LAB-03 메모리 계층표 — 실측으로 채우기
survey.sh 출력과 강의 자료의 대표 지연값을 이용해 완성한다.

| 계층 | 용량(실측) | 라인/페이지 | 대표 지연(cycle) | 근거 출력 줄 |
|------|-----------|-------------|------------------|--------------|
| L1 I / L1 D | | | ~1 | |
| L2 | | | ~4 | |
| L3 (있다면) | | | ~12 | |
| DRAM | | | ~200 | |
| 저장장치 | | - | (매우 큼) | |

## 서술형
1. meminfo 실행 결과에서 스택과 힙이 "서로 마주 보며 자라는" 배치인지 주소 근거로 판정하라.
2. MMIO 접근에 volatile이 필요한 이유를 캐시·컴파일러 최적화 관점에서 2문장으로 설명하라.
3. (심화) 64비트 빌드에서 포인터가 8바이트임에도 실제 유효 주소 폭이 더 좁은 이유를 조사하라.
